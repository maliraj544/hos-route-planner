# Submission checklist

- [ ] Push this project to GitHub.
- [ ] Deploy backend to Render.
- [ ] Deploy frontend to Vercel.
- [ ] Set `VITE_API_URL` on Vercel.
- [ ] Set `CORS_ALLOWED_ORIGINS` on Render.
- [ ] Test a short route and a multi-day route.
- [ ] Test current cycle values such as 0, 60, and 69.
- [ ] Record a 3–5 minute Loom.
- [ ] Submit GitHub URL + Vercel URL + Loom URL.
